# M1 progress: iOS app

M1 builds the iOS app: a Rust core over matrix-rust-sdk, a Flutter UI, and
in-app account linking through the Hub. See the delivery plan in
[spec.md](spec.md). This file is updated as work lands.

## Layout

| Path | What |
| --- | --- |
| `core/` | `switchboard_core`, Rust 1.99.1 (pinned in `rust-toolchain.toml`), matrix-sdk 0.19.1 and matrix-sdk-ui 0.19.1 |
| `core/src/api/` | Everything Dart can call: `client.rs` (session, sync, chat list, timeline, media, Hub) and `types.rs` (plain data) |
| `core/src/convert.rs` | SDK values to the plain types |
| `app/` | Flutter 3.47 app, iOS only for now. Riverpod 3 and go_router |
| `app/lib/src/rust/` | Generated by flutter_rust_bridge 2.13. Regenerate with `flutter_rust_bridge_codegen generate` in `app/` |
| `app/lib/src/state/` | Session, chat list, timeline, media and Hub state |
| `app/lib/src/ui/` | Screens and widgets |
| `app/tool/` | `sim-build.sh` (debug Simulator build that signs in by itself) and `sim-shot.sh` (open a route and screenshot). Testing uses its own Simulator, "Switchboard iPhone 16 Pro" |

## Notifications (paid route, from 30 Oct)

With a paid Apple Developer account (from 30 Oct), push follows the spec's paid route rather than ntfy:

- Server: `sb push KEY_ID TEAM_ID TOPIC` adds Sygnal (Compose profile `ios-push`) with the APNs key at `deploy/secrets/apns.p8`. Apps `com.richarddraycott.switchboard` (production) and `.dev` (sandbox, for development-signed installs). Synapse may reach the Compose network (`ip_range_whitelist`). `sb test` checks Synapse reaches Sygnal and that APNs accepts the key.
- App: Settings → Notifications registers the APNs token as an `event_id_only` pusher. The session is shared with a notification service extension through a keychain group; the extension fetches the event over the tailnet and shows chat, sender, network and text, or keeps "New message". Taps open the chat. While the app is open, it shows nothing extra.
- `app/tool/add_notification_extension.sh` adds the extension target (already done; safe to rerun). `app/tool/test-notification-service.sh` checks the extension's wording on macOS and can render a real event.
- Installs are now signed by the paid team: profiles last a year, and the three-app limit is gone.

## Notes

- Debug app builds compile the Rust dependencies at `opt-level = 3`. Unoptimised, the store's key derivation took about 40 s at first sign-in.
- The test room "Switchboard test" was created on the server to exercise the list and timeline. It is safe to leave or delete.
- Free personal-team signing allows only 3 apps from the team on the phone at once. Installing Switchboard may mean removing one of the other free-team apps first.
- Signal links by QR only, and a phone can't scan its own screen. Until a second Switchboard app exists, the QR needs showing on another screen to link Signal from the iPhone.
